# Training Mini-games

This directory will hold PixiJS-based training mini-games introduced in Milestone 2 (M2):
- Pace: Sprint drill
- Shooting: Target practice
- Passing: Rondos / accuracy passing
- Dribbling: Cone weaving
- Defending: Tackle timing
- Physical: Endurance challenge
- GK: Shot stopping

Each mini-game will return a performance grade (A/B/C) converting to attribute XP.
